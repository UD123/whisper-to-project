# Галерея объектов: без звука, четыре новых ролика и логотип Balluff

## Звук

Все ролики галереи пересобираются полностью без звуковой дорожки (не «приглушены», а
дорожки нет вообще), плюс в плеере остаётся флаг «без звука». Так звук не появится
ни при каком поведении браузера.

## Четыре новых примера

Было 12 карточек, станет 16. Добавляем сюжеты, которых ещё нет:

1. **Dispensing** — нанесение материала по траектории: точность позиционирования,
   а не захват.
2. **Сборка мебели (IKEA)** — крупные бытовые детали и работа по инструкции.
3. **Грибы** — мягкие органические объекты без CAD-модели.
4. **Наблюдение за человеком** — мониторинг активности человека в ячейке.

## Логотипы в блоке оборудования

- Balluff сейчас показан текстовой плашкой «Balluff / Matrix V» — заменяем настоящим
  логотипом с тем же приглушённым видом и цветом при наведении.
- Пункт «Miniature USB RGB» из списка камер убираем.
- Mitsubishi остаётся без изменений.

## Что увидит пользователь

Те же карточки-обложки, 16 штук вместо 12; клик открывает окно с видео — тихим.
В блоке оборудования появляется Balluff.

## Технические детали

- Новые ролики скачиваются из той же папки Drive, режутся до 8 с, 960×540, 25 fps,
  тот же холодный грейдинг, H.264/yuv420p, faststart, `-an`; постер — JPEG первого кадра.
- Существующие 12 роликов перекодируются с `-an`, новые `.asset.json` пишутся через
  `lovable-assets`, старые указатели заменяются.
- Новые записи и подписи EN/ZH — в `src/content/object-gallery.ts`.
- Balluff: `src/assets/logos/balluff.svg`, регистрация в `BrandLogo.tsx`, добавление
  в список в `Ecosystem.tsx`.
- В `.github/workflows/deploy-pages.yml` новые видеофайлы попадают в список копируемых медиа.
- Проверка: `bun run build`, клик по карточке в Playwright, `ffprobe` подтверждает
  отсутствие аудиопотока, скриншот блока оборудования с Balluff.
