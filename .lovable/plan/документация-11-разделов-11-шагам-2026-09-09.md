# Документация: 11 разделов = 11 шагам

## Цель
Сейчас карта «Main steps» заявляет 11 шагов, а пронумерованных разделов на странице только 7 — шаги 7–9 (загрузка данных, создание модели, тест) потеряны. Приводим страницу к строгому соответствию исходному Google-документу: 11 шагов в карте = 11 пронумерованных разделов-аккордеонов.

## Новая структура разделов

```text
01 — Get the software          (новый короткий раздел: POC + документация)
02 — Installation & verification  (текущий 01: требования, установка, проверка USB)
03 — Camera & optics           (текущий 02)
04 — Object scanning           (текущий 03)
05 — Camera calibration        (текущий 04)
06 — Object measurements       (текущий 05)
07 — Upload data to RobotAI    (новый: что именно отправить — images, calibration, size)
08 — Your model by RobotAI     (новый: мы создаём модель и делимся ею с вами)
09 — Test the detection        (новый: тест по аналогии с USB-моделью, ссылка на verification)
10 — Camera–robot calibration  (текущий 06)
11 — Robot communication       (текущий 07)
```

## Что делаем

1. **Три новых раздела (07–09)** — только факты из исходного документа, без выдуманных параметров:
   - *Upload data*: собрать папку объекта (изображения, данные калибровки, размеры) и отправить RobotAI. Оформим как чек-лист из 3 пунктов.
   - *Your model*: RobotAI строит модель и передаёт её вам — короткий информационный раздел с CTA «Contact RobotAI».
   - *Test the detection*: тестировать по тем же шагам, что и проверка USB в разделе 02 — перекрёстная ссылка-якорь на `#verification`, без дублирования инструкций.
2. **Перенумерация** существующих разделов 02–07 → 03–06, 10, 11 в `guide-sections.ts`, `guide-sections.zh.ts`, заголовках и оглавлении.
3. **Раздел 01 «Get the software»**: ссылка на POC, упоминание документации; установка и verification переезжают под номер 02. Якорь `#verification` сохраняется.
4. **Оглавление слева**: 11 пунктов с номерами 01–11; Verification остаётся вложенным подпунктом под 02.
5. **Карта «11 шагов»**: href каждого шага теперь ведёт на одноимённый раздел.
6. **Китайская версия**: полный перевод трёх новых разделов, обновление номеров.
7. **Проверка**: `bun run build`, затем Playwright — все 11 аккордеонов открываются, якоря из карты шагов ведут на правильные разделы, EN/中文 переключаются, нет ошибок консоли.

## Технические детали
- Файлы: `src/content/guide.ts`, `src/content/guide.zh.ts`, `src/content/guide-sections.ts`, `src/content/guide-sections.zh.ts`, `src/routes/guide.tsx`, при необходимости `src/components/site/guide/GuideSidebar.tsx`.
- ID якорей: новые `get-software`, `upload-data`, `model`, `test-detection`; существующие (`#optics`, `#scanning`, …) не меняются, чтобы не ломать ссылки.
- Контент новых разделов — строго по исходному тексту документа; недостающие артефакты (POC-ссылка, usb_test.zip) остаются с пометкой «Link on request».
