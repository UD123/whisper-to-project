# План: цветные, но приглушённые логотипы в Ecosystem

## Что делаем

Пересобираем отображение брендов в секции **04 — Ecosystem**:
- Логотипы всегда показываются в фирменном цвете (не в чёрно-белом).
- По умолчанию к ним применяется фильтр, который приглушает цвета до уровня, уместного для светлой Clean Lab-палитры (`#F4F5F7` фон, `#FFFFFF` карточки, `#111827` текст).
- При наведении логотип плавно возвращается к исходной яркости фирменного цвета.
- Монохромный fallback сохраняется для неизвестных брендов.

## Куда вносить правки

- `src/components/site/BrandLogo.tsx` — заменить классы по умолчанию (`grayscale opacity-60`) на приглушённый цветной фильтр.
- Возможно, `src/styles.css` — если для единообразия фильтра удобнее вынести CSS-утилиту (например, `.logo-muted`).
- `src/components/site/Ecosystem.tsx` — без изменений, если структура чипов уже устраивает.

## Техническая реализация

- Tailwind-класс по умолчанию: `saturate-[0.7] brightness-[0.92] opacity-90` (или близкое сочетание), чтобы цвета были узнаваемы, но не кричали.
- Hover-класс: `group-hover:saturate-100 group-hover:brightness-100 group-hover:opacity-100`.
- Переход оставляем текущий (`transition duration-300`).
- Все локальные SVG-логотипы остаются без изменений; применение цветного фильтра работает поверх них автоматически.

## Результат

Сетка узнаваемых брендов в «лабораторно приглушённых» фирменных цветах по умолчанию; при наведении логотип оживает до полного цвета. Визуально это уже не кричащий "зоопарк" цветов, но и не мёртвый grayscale.
