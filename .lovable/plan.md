# Галерея объектов: убрать звук и добавить два новых ролика

## Звук

Все ролики галереи пересобираются полностью без звуковой дорожки (не «приглушены», а
дорожки нет вообще), плюс в самом плеере остаётся флаг «без звука». Так звук не появится
ни при каком поведении браузера.

## Два новых примера

Сейчас в галерее 12 карточек. Предлагаю добавить два сюжета, которых ещё нет:

1. **Dispensing** (`Dispensing - testing precise positioning and image sensitivity`) —
   нанесение материала по траектории: показывает точность позиционирования, а не захват.
   В галерее нет ни одного «не-pick» сценария.
2. **Сборка мебели** (`Ikea Furniture Assembly Tips with Objects and Text`) —
   крупные бытовые детали и работа по инструкции; отличается и по объекту, и по сцене.

Запасные варианты, если эти не понравятся: `MatchBox` (мелкие картонные коробочки),
`Mushroom` (мягкие органические объекты), `Human Activity Monitoring` (наблюдение за
человеком в ячейке).

## Что увидит пользователь

Те же карточки-обложки, 14 штук вместо 12. Клик открывает окно с видео — тихим.

## Технические детали

- Оба новых ролика скачиваются из той же папки, режутся до 8 с, 960×540, 25 fps,
  тот же холодный грейдинг, H.264/yuv420p, faststart, `-an`; постер — JPEG первого кадра.
- Существующие 12 роликов перекодируются с `-an` (copy видео + drop audio), новые
  `.asset.json` пишутся через `lovable-assets`, старые указатели заменяются.
- В `ObjectGallery.tsx` у `<video>` остаётся `muted` и добавляется `defaultMuted`-поведение
  через ref, чтобы автозапуск не включал звук.
- Новые записи и подписи EN/ZH добавляются в `src/content/object-gallery.ts`.
- В `.github/workflows/deploy-pages.yml` новые файлы попадают в список копируемых медиа.
- Проверка: `bun run build` + клик по карточке в Playwright, `ffprobe` подтверждает
  отсутствие аудиопотока.
