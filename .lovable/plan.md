# План: узнаваемые логотипы брендов в секции Ecosystem (04)

## Что удалось найти

Проверила доступность источников из песочницы. Аутентичные векторные логотипы (SVG) доступны для скачивания:

**Роботы (9 из 11):**
- FANUC, ABB, Hanwha, Denso, Mitsubishi, Yaskawa — с векторного CDN
- KUKA, Universal Robots, Yaskawa — с Wikimedia Commons

**Камеры (2 из 4):**
- Basler, IDS — с векторного CDN

**Не нашлось в открытых источниках (5):** Nachi, Dobot, RealSense, Allied Vision, TM Robots (Techman).

## Что делаем

1. **Скачиваем аутентичные SVG** для 11 брендов и сохраняем локально в `src/assets/logos/` — сайт не будет зависеть от внешних CDN при загрузке (важно для надёжности превью и публикации).

2. **Для 5 недостающих брендов** (Nachi, Dobot, RealSense, Allied Vision, TM Robots) рисую аккуратные SVG-вордмарки вручную: у этих брендов логотипы — по сути текстовые начертания, так что стилизованная типографика в фирменном духе будет выглядеть узнаваемо. Если какой-то получится неубедительным — оставлю для него текущий mono-бейдж.

3. **Переписываю `BrandLogo.tsx`**: вместо внешних ссылок — локальные SVG-ассеты.

4. **Стайлинг по вашему ТЗ:**
   - по умолчанию: grayscale + opacity 60% (монохром под Clean Lab);
   - при hover: плавный переход к полной непрозрачности и оригинальному фирменному цвету;
   - единая высота логотипов, выравнивание по базовой линии, чипы с тонкой рамкой `#E5E7EB`.

5. **Заодно чиню мелочь:** в списке роботов сейчас есть дубль «Hana» (опечатка от Hanwha) — уберу.

## Результат

Сетка узнаваемых логотипов роботов (FANUC, KUKA, ABB, Yaskawa, UR и др.) и камер в фирменных цветах по наведению, монохромные в покое — в духе текущего дизайна, без перегруза.

## Технические детали

- Источники: cdn.worldvectorlogo.com, upload.wikimedia.org (проверены, отвечают 200).
- Файлы: `src/assets/logos/*.svg`, правки в `src/components/site/BrandLogo.tsx` и `src/components/site/Ecosystem.tsx`.
- Логотипы — товарные знаки их владельцев; использование в разделе «совместимость» (nominative fair use) — стандартная практика для интеграционных страниц.
