# Сверка документов и что добавить в инструкцию на сайте

## Какой документ наш

- **Pose6D-User Guide for POC — 0919.docx** (первая ссылка) — это наш документ, из него сделана страница Documentation. Совпадают требования (Windows 10, 8 ГБ, без GPU, 250×250 px), пути `C:\RobotAI\SW`, `C:\RobotAI\Parts`, usb_test и оба сценария проверки.
- **Pose6D-User Guide-0709.docx** (вторая ссылка) — другой, гораздо более объёмный документ: полное руководство по продукту (обзор, компоненты системы, интеграция с роботом, связь, полный процесс), 182 иллюстрации. На сайт он не переносился.

## Чего не хватает на сайте (из нашего документа 0919)

1. **Создание нового объекта** — сейчас этого шага нет вообще:
   - `Project → Set Work Directory` (например `C:\RobotAI\Parts`);
   - ввод имени объекта в поле параметров (в документе пример «Tube24»);
   - `Projects → Create New Object` — создаётся папка объекта;
   - `Projects → Check Config File` — проверка, что создано 5 директорий;
   - напоминание отредактировать пример json-файла в папке `labels` под свой объект.
2. **Установка полученной модели и её тест** — на сайте шаг 09 описан общими словами, в документе есть точные действия:
   - положить zip с моделью в `C:\RobotAI\Parts`, имя zip должно совпадать с именем объекта;
   - `Training → Unzip Model Zip File`;
   - `Detect → Run Standalone from File`, затем `Detect → Run Stand Alone with Camera`;
   - без лицензии показывается только 3D-ось, с лицензией — числовые значения.
3. **Активация и типы лицензии** — раздела на сайте нет совсем:
   - при запуске из `C:\RobotAI\SW` появляется надпись «Requires Activation»;
   - в этой же папке создаётся файл `pose6d_license.chk`, его нужно отправить в RobotAI вместе с названием компании;
   - в ответ приходит файл, который открывает работу для конкретных машин, срока и функций;
   - тип лицензии влияет на подключение к роботам и на то, какие данные выводятся.
4. **Уточнение параметров в разделе «Камера и оптика»** — в документе для POC указано «объект не меньше 200×200 px при кадре около 1280×720, ⅓–¼ кадра», а общее требование — 250×250 px. Сейчас на странице эти два числа разведены нечётко; стоит показать оба с пояснением, где какое действует.

## Скриншоты — главный пробел

В документе **30 изображений**, на странице **ни одного реального скриншота программы** — только перерисованные схемы и видео. Не хватает снимков экрана к шагам:

- главное окно после запуска;
- `Project → Select Object Directory` и выбор `usb_test`;
- окно `Check Config File` с сообщением «Config is OK»;
- `Detect → Run Video from File` и окно с видео USB;
- `Camera → Select from List`, выбор Webcam 0/1;
- `Camera → Configure → Resolution`;
- окно живого видео с камеры;
- структура папки usb_test;
- `Set Work Directory`, ввод имени объекта, `Create New Object`, 5 созданных папок;
- результат детекции без лицензии (только оси) и с лицензией (с числами);
- окно «Requires Activation» и вид с реальными числами на usb_test.
