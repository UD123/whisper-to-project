# Раздел с инструкциями по установке (Documentation)

Всё содержимое переносим на сайт: никаких ссылок на Google Docs. PDF и видео открываются прямо в наших окнах, в стиле сайта.

## Где размещаем

Новая отдельная страница `/guide` — «Documentation».

- В шапке кнопка «Developer Docs» ведёт на `/guide` (сейчас она указывает на блок Specs).
- В подвале — ссылка «Documentation».
- Слева на странице липкое меню разделов, справа — содержимое. На телефоне меню сворачивается в список сверху.
- Сверху страницы — та же навигация и подвал, что на главной, чтобы стиль совпадал.

## Что будет на странице (первый заход)

**Шапка раздела**
Заголовок «Pose6D — Getting Started», подпись «Main steps for 3D pose estimation», дата обновления и кнопка «Скачать полное руководство».

**Overview**
Короткое вступление: это краткая версия руководства; полная версия — по запросу у RobotAI.

**Main steps (11 шагов)**
Пронумерованный маршрут из твоего текста. Каждый шаг — карточка с номером, названием и одной поясняющей строкой. Вместо ссылок на Google Doc каждая ведёт на соответствующий раздел этой же страницы (пока не готовые — помечены «coming soon», без битых ссылок).

**Видеогид**
Ролик «How to start and test Pose6D using a USB object» — скачаем и разместим у нас, играет прямо на странице, в такой же тёмной технической рамке, как остальные видео сайта.

**Раздел 01 — Hardware & Software Installation** (полностью)
1. Requirements — компактная таблица: Windows 10, 8 ГБ памяти, GPU не обязателен (без него медленнее), в отдельных случаях CUDA, драйверы камеры (USB — встроенный, прочие — по запросу).
2. Важное правило в виде выделенной плашки: объект в кадре — не меньше 250×250 пикселей.
3. Схема подключения «камера → компьютер RobotAI → контроллер робота» — картинка из руководства в нашей рамке.
4. Installation — 4 шага с путями папок; пути оформлены моноширинным шрифтом с кнопкой «копировать».
5. Verification — две вкладки: «Recorded USB data» и «Your own USB camera», внутри пошагово с пунктами меню программы и скриншотами из руководства.
6. Файлы раздела: полное руководство PDF и калибровочная доска PDF — открываются в окне просмотра прямо на сайте (кнопка «Скачать» рядом). Тестовый архив `usb_test.zip` пока не выкладываем — скажи, если нужен, добавлю ссылку на скачивание.

Остальные разделы (setup, сбор данных, калибровка, размеры, тест, робот) добавим, когда пришлёшь текст — структура и меню уже будут готовы.

## Как упрощаем текст (пункты и параметры не меняем)

- Требования — таблицей, а не абзацем.
- Длинные фразы вида «Select Menu bar>Project>Check Config File» — как цепочка меню: `Project → Check Config File`.
- Каждый шаг — одно действие и один ожидаемый результат («должно появиться окно…»).
- Все числа (8 ГБ, 250×250 px, 320×240, 1280×720, ⅓–¼ кадра) сохраняем дословно и выносим в заметные плашки.

## Техническая часть

- Новый файл `src/routes/guide.tsx` + компоненты в `src/components/site/guide/` (Sidebar, StepList, StepCard, CalloutBox, PdfViewer, CodePath).
- Тексты — в `src/i18n/dictionaries.ts` (секция `guide`), пока с английскими строками.
- Видео: скачиваю ролик с YouTube, привожу к нашей цветокоррекции, загружаю через lovable-assets и показываю через существующий `MediaSlot`/`AutoVideo`.
- Скриншоты и схема: извлекаю страницы PDF в изображения, загружаю как ассеты.
- PDF-просмотр: встроенный объект/iframe на файл с нашего домена, поверх — наша рамка и кнопка скачивания.
- `.github/workflows/deploy-pages.yml`: расширяю правило переноса медиа на `.pdf`, чтобы документы тоже отдавались с нашего домена на GitHub Pages.
- `head()` страницы `/guide`: свой title и описание.
