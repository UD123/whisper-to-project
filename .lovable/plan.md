# Видео деталей в разделе Object Catalog

Папка открыта — в ней около 44 разных роликов (bin picking, электроника, сборка,
конвейер, ткань, продукты, специфичные детали). Класть их все на сайт нельзя:
страница станет тяжёлой и посетитель потеряется.

## Что предлагаю

Раздел «Object Catalog» (сейчас — только текстовые плашки с названиями деталей)
превращается в **галерею примеров**: список категорий остаётся, а под ним
появляется сетка карточек с реальными кадрами объектов.

Ключевое правило, чтобы сайт не потяжелел:

- на странице сразу видны только **картинки-обложки** (первый кадр ролика,
  ~60–120 КБ каждая), видео не загружается;
- ролик подгружается и играет **только по клику** — открывается в аккуратном
  окне поверх страницы, в том же тёмном «техническом» оформлении, что и
  остальные видео на сайте;
- берём **10–12 самых показательных роликов**, а не все 44;
- каждый ролик режем до 6–10 секунд, приводим к общей цветокоррекции сайта и
  сжимаем — примерно 0.5–1.5 МБ вместо десятков мегабайт.

Итог: вес страницы вырастает примерно на 1 МБ обложек, а не на 300+ МБ видео.

## Какие ролики предлагаю взять (по 2 на группу)

- Bin picking: `BinPicking WithoutCaps`, `Multiple Object Picking`
- Электроника: `ElectronicCard-Detection`, `ElectronicBoard-Hans`
- Сборка: `HamLet-Assemble`, `Ikea Furnature Assemble`
- Гибкие/нестандартные объекты: `Garment picking - Short2`, `Mushroom`
- Конвейер и коробки: `conveyor_out`, `Box detection and positioning`
- Точность: `ElectronicCard-Precision`, `HexPartPickUp`

Список можно поменять — скажите, если какие-то ролики важнее.

## Что увидит пользователь

```text
OBJECT CATALOG
категории деталей (как сейчас)
------------------------------------------------
[ обложка ]  [ обложка ]  [ обложка ]  [ обложка ]
 bin picking   плата        сборка       ткань
[ обложка ]  [ обложка ]  [ обложка ]  [ обложка ]
```
Клик по карточке → всплывает окно с видео, подпись «что за объект» и
«что делает система».

## Технические детали

- Новый компонент `src/components/site/ObjectGallery.tsx`, встраивается внутрь
  `ObjectCatalog.tsx` под списком категорий.
- Модальное окно — `Dialog` из shadcn; видео монтируется только при открытии
  (`preload="none"` до этого), поэтому трафика до клика нет.
- Ролики скачиваются из папки, обрезаются и кодируются ffmpeg
  (H.264, yuv420p, faststart, тот же холодный грейдинг, что в `media-grade`),
  постеры — JPEG первого кадра.
- Файлы уходят в CDN через `lovable-assets`, пути кладём в
  `src/content/object-gallery.ts` (по образцу `src/content/guide-media.ts`).
- Workflow GitHub Pages уже копирует CDN-видео в `dist/client/media/` — новые
  ролики добавляются в тот же список, чтобы работали на домене.
- Подписи EN/ZH — в `src/i18n/dictionaries.ts`, рядом с блоком `catalog`.
